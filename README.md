# PeoplePulse HRMS

A Human Resource Management System built using Next.js.

## Technologies Used

- Next.js
- React.js
- TypeScript
- Tailwind CSS
- Lucide React
- Recharts

## Features

- Dashboard
- Employee Management
- Attendance Management
- Leave Management
- Payroll Management

## Getting Started

Install dependencies:

npm install

Run the development server:

npm run dev
